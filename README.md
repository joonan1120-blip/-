# 냉장고 식단 에이전트

냉장고 재료로 한 끼 메뉴를 찾고, 인원별 필요량·부족량을 코드로 계산하는 Streamlit 챗봇입니다(카카오톡 테마, Python 3.12).

## 실행

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env   # OPENAI_API_KEY 입력
streamlit run app.py
```

## 구조 (메인 / 서브 에이전트)

| 구성 | 역할 |
|---|---|
| 메인 에이전트 (`core/agents.py` `MainAgent`) | LLM(`gpt-6.1-sol`, 추론 수준 low). 질문에 필요한 도구만 tool-calling 으로 선택, 호출 상한·실패 처리 |
| 재고 에이전트 | `get_inventory` 실행 |
| 레시피 에이전트 | `list_menus`, `get_recipe` 실행 |
| 식단 에이전트 | `search_menu_candidates`, `calculate_requirements` 실행 |

서브 에이전트는 LLM 없이 도구만 실행하고 실행 기록(도구·인자·성공/실패·반환 요약)을 남깁니다.
수량 계산은 `core/tools.py`의 코드가 하며(필요량 = 기준량 × 인원 ÷ 기준인원, 부족량 = max(필요 − 보유, 0), 반올림 없음, 단위가 다르면 계산 보류), 화면 표는 도구 반환값을 그대로 보여 줍니다.

## 데이터 수정

- **냉장고 / 레시피 탭**에서 표로 직접 수정·추가·삭제 → `변경 적용`(검증 통과 시에만 반영, 이 세션 한정).
- 재료ID·레시피ID는 자동 부여됩니다. 레시피 편집에서는 기존 재료를 검색해 선택하고, 새 재료는 `재료 등록`으로 추가합니다(새 ID 자동 할당).
- `원본 파일에 저장`은 확인 체크 후에만 `data/`의 파일을 덮어씁니다.
- 다른 CSV/JSON으로 교체 업로드 가능. 오류(음수·중복ID·JSON 손상·기준인원 0 등)가 있으면 원인과 위치를 보여 주고 채팅을 멈춥니다. 정상 파일로 바꾸거나 `기본 파일로 되돌리기`로 복구합니다.

## 레시피 데이터

- `data/레시피.json`: 수업용 기본 레시피 8개(R01~R08) + 자취요리 100개(R09~R108). 자취요리는 [만개의레시피](https://www.10000recipe.com)의 공개 레시피 중 간단한 것을 골라 재료·분량을 옮기고, 각 레시피에 `출처` URL을 남겼습니다.
- 조리 순서는 원문을 그대로 옮기지 않고 핵심만 요약해 다시 썼습니다. 정확한 방법과 사진은 `출처` 링크의 원문을 보세요.
- 이 앱은 단위를 `g`/`개`만 쓰므로 큰술·컵·줌 등은 g로 환산했습니다(큰술 15g, 재료별 밀도 보정 등). 정량이 없거나 개수를 g로 바꾼 값은 일반적인 분량으로 추정했고, 해당 재료에는 `"추정": true`가 붙어 있습니다. 실제 요리 전에 확인하세요.
- 냉장고는 12종뿐이라 대부분의 자취 레시피는 ‘미등록 재료’가 많아 부족 재료가 길게 나옵니다. 냉장고 탭에서 재료를 추가해 쓰세요.
## 설정(.env)

모델, 추론 수준, 응답 제한 시간(`REQUEST_TIMEOUT`, 예: 0.01로 시간 초과 시험 → 기록에 ‘시험용 실패’ 표시), 도구 호출 상한(`MAX_TOOL_CALLS`)은 `.env`에서 바꿉니다. 변경 후 앱을 다시 시작하세요.
`새 대화` 버튼은 대화만 비우고 데이터는 유지합니다. 도구 실패·호출 상한 시험은 아래 모의 시험으로 확인합니다.

## 테스트 (API 키 불필요)

```bash
python -m unittest discover tests
```

`tests/test_core.py`는 계산·검증, `tests/test_agent.py`는 가짜 모델 응답을 쓰는 **모의 시험**입니다(실제 LLM 호출 아님).

## 배포 (Streamlit Community Cloud)

1. 이 폴더를 GitHub 저장소로 올립니다(.env는 올리지 않습니다).
2. share.streamlit.io 에서 저장소를 연결하고 Main file 을 pp.py, Python 을 3.12 로 지정합니다.
3. App settings → Secrets 에 아래를 넣습니다(최상위 키는 환경변수로 읽힙니다).

```toml
OPENAI_API_KEY = "sk-..."
OPENAI_MODEL = "gpt-6.1-sol"
```

배포본은 파일 저장(원본 파일에 저장)이 서버 재시작 시 초기화될 수 있으니, 데이터를 영구히 바꾸려면 저장소의 data/ 파일을 직접 수정하세요.

## 주의

교육용 자료입니다. 조리 순서는 예시이며 식품 안전·영양 적합성을 검증하지 않았습니다. 재료 제외는 선호 반영일 뿐 알레르기 안전을 보장하지 않습니다. `.env`와 키 값은 공유하지 마세요.
